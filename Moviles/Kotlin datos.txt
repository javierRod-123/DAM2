Declaración variable:

	Se usa val para una variable cuyo valor nunca va a cambiar, y se usa var cuando una variable puede cambiar

		var count: Int = 10

		val languageName: String = "Kotlin"

Condicionales:

	Aquí las condiciones del if son exactamente iguales a las de Java pero en vez de un if se podría usar un when
	
	val answerString = when {
    count == 42 -> "I have the answer."
    count > 35 -> "The answer is close."
    else -> "The answer eludes me."
}

println(answerString)
	
Funciones:

	Para crear funciones se necesita la palabra fun para luego definir el tipo de entrada
	
	Funcion sin ninguna entrada: 
	
	fun generateAnswerString(): String {
    val answerString = if (count == 42) {
        "I have the answer."
    } else {
        "The answer eludes me"
    }

    return answerString
}

	Llamada función: val answerString = generateAnswerString()
	
	Funcion con argumentos de entrada:
	
	fun generateAnswerString(countThreshold: Int): String {
    val answerString = if (count > countThreshold) {
        "I have the answer."
    } else {
        "The answer eludes me."
    }

    return answerString
}

	Llamada función: val answerString = generateAnswerString(42)
